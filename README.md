# 📊 OC-kospi-point (코스피 일별 마감가 수집 프로그램)

> **OpenCode와 함께 바이브코딩 첫 경험하기** 🚀

대한민국 코스피(^KS11) 지수의 일별 마감가를 수집하여 **텍스트 파일(.txt)** 및 **시각화된 HTML 파일(.html)**로 저장해 주는 Python 프로그램입니다.

🌐 **웹 페이지 링크**: [https://keynutai.github.io/OC-kospi-point/](https://keynutai.github.io/OC-kospi-point/)

---

## 🌟 주요 기능

- **Yahoo Finance (`yfinance`)** 기반의 실시간/과거 데이터 자동 수집
- 2026년 1월 1일부터 오늘 날짜까지의 코스피 일별 마감가 수집
- **2025년 마지막 거래일 종가 기준** 첫 거래일(2026-01-02) 전일대비 등락률 정확히 계산
- **전일 대비 등락 표시** — **등락 (pt)** / **등락 (%)** 2개의 별도 컬럼으로 분리:
  - **등락 (pt)**: 등락 포인트, 화살표·색상 없는 일반 텍스트 (예: `+95.46`)
  - **등락 (%)**: 등락률, 🔴 **상승** (`▲ +X.XX%`) 빨간색 / 🔵 **하락** (`▼ -X.XX%`) 파란색
- **월별 구분선** 제공 (중앙 정렬 + 흰색 텍스트)
- **인터랙티브 정렬 기능**: HTML 페이지에서 버튼 클릭 한 번으로 **`⏳ 최신순`** / **`⌛ 과거순`** 날짜 정렬 전환 가능
- 모던한 **다크 모드 HTML 결과물** 및 주요 통계 카드 (최고가, 최저가, 평균가, 최근가) 제공
- **GitHub Pages 연동**: 웹 주소를 통해 누구나 실시간 마감가 페이지 접속 가능
- **간편한 실행 환경**: macOS Finder에서 더블클릭만으로 데이터 수집이 가능한 `.command` 실행 파일 제공

## 📁 파일 구성 및 결과물 예시

1. `run_kospi.command`: 더블클릭하여 프로그램을 바로 실행하는 macOS 전용 실행 파일
2. `kospi_closing_prices.txt`: 깔끔하게 정렬된 콘솔용 텍스트 문서
3. `kospi_closing_prices.html` / `index.html`: 모던 웹 스타일의 인터랙티브 리포트 (GitHub Pages용)

## 🚀 실행 방법

### 🖱️ 방법 A: 마우스 더블클릭으로 실행 (추천)
Finder에서 `run_kospi.command` 파일을 더블클릭하면 터미널 창이 열리면서 자동으로 데이터를 최신 상태로 수집 및 갱신합니다.

---

### 💻 방법 B: 터미널에서 직접 실행

#### 1. 저장소 클론
```bash
git clone https://github.com/keynutai/OC-kospi-point.git
cd OC-kospi-point
```

#### 2. 가상환경 생성 및 패키지 설치
```bash
python3 -m venv kospi_venv
source kospi_venv/bin/activate
pip install yfinance
```

#### 3. 스크립트 실행
```bash
python kospi_fetch.py
```
*(실행 후 해당 폴더에 `kospi_closing_prices.txt`, `kospi_closing_prices.html`, `index.html`이 자동 생성/업데이트됩니다.)*

## 🔄 작업 내역 (Changelog)

### 2026-08-16 · 전일대비 표시 개편

전일 대비 등락을 한 칸에 합쳐서 보던 것을 **등락 포인트(pt)** 와 **등락 비율(%)** 을 2개의 별도 컬럼으로 분리하여, 수치와 비율을 한눈에 구분할 수 있도록 개선했습니다.

| 구분 | 변경 전 | 변경 후 |
|------|---------|---------|
| 표시 구조 | 1열에 합침 (`+2.27% (+95.46pt)`) | **등락 (pt)** / **등락 (%)** 2열 분리 |
| 등락 (pt) | — (괄호 안에 포함) | 화살표·색상 없는 일반 텍스트 (`+95.46`) |
| 등락 (%) | 화살표 + 색상 | 유지 (🔴 `▲ +2.27%` / 🔵 `▼ -0.76%`) |

**구체적 변경 사항**
- `Point_Change` 계산 로직 추가: `df["Point_Change"] = df["Close"].diff()`
- **텍스트(.txt)**: `등락(pt)` / `등락(%)` 컬럼 2개로 분리 출력
- **HTML**: 테이블 4열 구조 (`날짜 | 마감가 | 등락 (pt) | 등락 (%)`), 월 구분선 `colspan` 3→4 조정
- **등락 (pt) 컬럼**: 화살표·색상 제거, 본문 기본 색상 일반 텍스트로 표시
- **등락 (%) 컬럼**: 기존 화살표·상하한 색상(빨강/파랑) 유지
- 미사용 `.point` CSS 클래스 정리 (기본 + 라이트 테마)
